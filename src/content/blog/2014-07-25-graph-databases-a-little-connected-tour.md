<div>EuroPython talk by: Francisco Fernández Castaño</div><div> </div><div><span style="text-decoration:underline;"><a href="https://ep2014.europython.eu/en/schedule/sessions/70/" target="_blank">https://ep2014.europython.eu/en/schedule/sessions/70/</a></span></div><div><span style="text-decoration:underline;"> </span></div><div>The talk was classified as novice and so it was - very basic graph database ideas.</div><div> </div><div>Castaño started by presenting the general idea of graph databases and showing some use cases.</div><div> </div><div>One of the most known use cases - social media data, friends-of-friends.</div><div> </div><div>Then he presented <a href="http://www.neo4j.org/" target="_blank">Neo4j</a> which is graph database written in Java but originally was written in Python. Neo4j is known to be very scalable and to support ACID transactions. Another nice property about Neo4j is the ability to extend the give rest API but your own needs.</div><div> </div><div>The next part of talked focused on the <a href="http://docs.neo4j.org/chunked/stable/cypher-query-lang.html">cypher language</a> - which is the way to query the Neo4j database. Neo4j have some nice UI properties and I really missed some reference or example for that on this talk.</div><div> </div><div>Last but not least tip given in the talk, you can try Neo4j without having to install it on your machine - <a href="http://www.graphenedb.com/" target="_blank">http://www.graphenedb.com/</a> (free sand box of up to 1k nodes and 10k edges).</div>
