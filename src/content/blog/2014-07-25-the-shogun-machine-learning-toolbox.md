<div>EuroPython talk by: Heiko Strathmann, <a href="http://herrstrathmann.de/" target="_blank">herrstrathmann.de</a></div><div> </div><div><a href="https://ep2014.europython.eu/en/schedule/sessions/103/">https://ep2014.europython.eu/en/schedule/sessions/103/</a></div><div> </div><div>Strathmann presented the <a href="http://www.shogun-toolbox.org/">Shogun toolbox</a>. Shogun is a Machine Learning toolbox which implement most of the common supervised and unsupervised algorithms. Shogun is implemented in C++ and interacts with Python as well as with Java, Ruby, Matlab, Lau, etc. Shogun is meant to run on single machine and no distributed.</div><div> </div><div>Shogun is an open source project started on 2004. It has 8 core developers + 20 contributors and it is fairly active. It also has a collebaration with <a href="http://www.google-melange.com/gsoc/homepage/google/gsoc2014">Google summer of code</a> - 29 projects so far, 8 on going.</div><div> </div><div>The C++ maybe the most significant advantage of Shogun over SciPy. It is simply faster and enables more efficient memory allocation and run time optimization and well as multi-language support . Therefore enabling training and classifying data based on larger number of samples and higher dimension.</div><div> </div><div>The binding \ interfaces to other languages is done using - <a href="http://www.swig.org/" target="_blank">http://www.swig.org</a>. </div><p>Building, bug tracing and deployment is done using - <a href="http://buildbot.net/">http://buildbot.net/</a>.</p><div> </div><div>Summarizing - Specially when going larger Shogun seems like a good alternative to SciPy (competition makes both products better). Shogun site offers some tutorials include <a href="http://www.shogun-toolbox.org/page/documentation/notebook">notebooks</a> and <a href="http://www.shogun-toolbox.org/page/documentation/demo">demos</a>.</div>
