<p><strong><span style="text-decoration:underline;">C3.JS</span></strong> - I have previously wrote a post about the importance of visualization in the skill set of data scientist. C3.js is a JavaScript chart library based on d3.js which seems at least in a glimpse to be simple and intuitive. I would like to see a Python client for that but that for the future to come.  </p><p><a href="http://c3js.org/" target="_blank">http://c3js.org/</a></p><p>nvd3 also do something  like - charts based 3d.js and also have a Python client which I worked with a bit. Comparing the two c3.js seems a little bit more mature than nvd3, ignoring the lack of Python client but I'm sure that gap would be filled soon. </p><p><a href="http://nvd3.org/" target="_blank">nvd3.org</a></p><p><strong><span style="text-decoration:underline;">Harvard Visualization course</span></strong> - I went through some of the slides and it was fascinating but what is even more exciting is the great collection of links about visualization examples, theory and tools. Great work.</p><p><a href="http://www.cs171.org/#!index.md" target="_blank">http://www.cs171.org/#!index.md</a></p><p><b><span style="text-decoration:underline;">textract</span></b> - I needed high flexibility of input types in a project I do and of course I wanted to deal with as transparent as possible without looking myself to all the relevant packages or adjust my code to the API of each package. Fortunately somebody already did it - textarct. The package is not perfect and there are some "glitches" mostly concerning the parsers themselves (line splitting, non-ascii, etc) and not to the unified API textract provides. However, it is a very good start.</p><p><a href="http://textract.readthedocs.org/en/latest/">http://textract.readthedocs.org/en/latest/</a></p><p><span style="text-decoration:underline;"><strong>Visualizing Garbage Collection Algorithms</strong></span> - both very cool visualization and good explanations. Design wise I think the visualization should be larger but the concept itself is very neat.</p><p><a href="http://spin.atomicobject.com/2014/09/03/visualizing-garbage-collection-algorithms/">http://spin.atomicobject.com/2014/09/03/visualizing-garbage-collection-algorithms/</a></p><p><span style="text-decoration:underline;"><strong>SmartCSV</strong></span> - making CSV reader more structured by defining a model and validating it while reading. Enables skipping rows (and soon skipping also columns). It is on going project and feature requests and issues are currently addressed quickly.</p><div><a href="https://github.com/santiagobasulto/smartcsv" target="_blank">https://github.com/santiagobasulto/smartcsv</a></div><p> </p>
