<div></div>
<div><b><span style="text-decoration:underline;">Typo Distance</span></b> - finds typo distance between two strings. It uses qwerty layout but you can configure different layout pretty easily. The algorithm is quite heavy and time consuming, there is some room for improvement (although it is not actively maintained). For example - adding a max parameter which stops the computation once the typo distance is higher than the allowed distance.</div>
<div><a href="https://github.com/wsong/Typo-Distance/blob/master/typodistance.py">https://github.com/wsong/Typo-Distance/blob/master/typodistance.py</a></div>
<div></div>
<b><span style="text-decoration:underline;">Topy</span></b> - Python script to fix typos in text, using rule-sets developed by <a href="https://en.wikipedia.org/wiki/Wikipedia:AutoWikiBrowser/Typos">theRegExTypoFix</a> project from Wikipedia. The basic rule set is an English rule set but other rule sets are also available. Trying it, I'm positive about it but it is not baked \ mature enough and I would like it to be more easy to use in code than as a command line tool.

<a href="https://github.com/intgr/topy">https://github.com/intgr/topy</a>
