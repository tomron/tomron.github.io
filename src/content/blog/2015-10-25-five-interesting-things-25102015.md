<strong><u>Snakefooding python</u></strong> - snakefood is a tool to create graph dependencies. This post show the dependency graphs for some very common python libraries (Flask, django, Celery, requests, etc.). It presents the pros and cons of using snakefood, what it exposes and what it does not expose (many small files -&gt; many imports -&gt; complex dependency graph vs one file, spaghetti code -&gt; no imports -&gt; very clear simple graph). I find it as a tool that supports developing and detecting non necessary dependencies.

<a href="http://grokcode.com/864/snakefooding-python-code-for-complexity-visualization/">http://grokcode.com/864/snakefooding-python-code-for-complexity-visualization/</a>
