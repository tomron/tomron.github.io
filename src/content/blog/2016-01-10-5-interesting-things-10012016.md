<strong><u>Everything.me open source their inheritance</u></strong> - Everything.me was an Israeli startup closed few weeks ago. They now open source major parts of their code and tools including their prediction algorithm, <a href="http://redash.io/" target="_blank">Re:dash</a> and others.

<a href="https://medium.com/@joeysim/everythingme-open-and-out-6ed94b436e4c#.uvyfq7n5x" target="_blank">https://medium.com/@joeysim/everythingme-open-and-out-6ed94b436e4c</a>

<strong><u>Python 3 module of the week</u></strong> - over the years Python Module of the week by Doug Hellman was one of the most reliable documentation resources for Python's standard library. The documentation is always accompanied with very good examples to almost any functionality. It is also available as a command line tool and was translated to Chinese, German, Italian, Spanish and Japanese. And.. it is now updated to Python version 3.5. Kudos.

<a href="https://pymotw.com/3/">https://pymotw.com/3/
</a>
