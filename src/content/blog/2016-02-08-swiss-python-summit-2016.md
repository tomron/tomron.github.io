<div><p>I participated in <a href="http://www.python-summit.ch/" target="_blank">Swiss Python Summit today</a>, where I gave a talk about "Python's guide to the Galaxy". Code and slides are available in my <a href="https://github.com/tomron/python_swiss_2016">GitHub</a>. All the talk were recorded and they will probably be online within a few hours \ days.</p></div>
<div><p><img class="  wp-image-589 aligncenter" src="/wp-content/uploads/2016/02/20160205_173113.jpg" alt="20160205_173113" width="325" height="581" /></p></div>
<div><p>Beside the best signs I can think of the program was great and very diverse in the topics - music, 3d graphics, astrophysics and so on. Even the order of the program was very good - super cool talks after lunch to keep everyone a wake. The speakers were also relatively diverse - 4 out of 9 speaker were women, different backgrounds, etc. Unfortunately there were only few women in the crowd.</p></div>
<div><p>I was very lucky to give the first talk so I could then concentrate on the other talks. One very strong point of the conference was the diversity of the talks.</p></div>
<div><p>The second was "API Design is Hard" by <a href="https://github.com/davidhalter" target="_blank">Dave Halter</a>, creator and maintainer of <a href="https://github.com/davidhalter/jedi" target="_blank">Jedi</a>. It was more conceptional talk then a technical one which was enriched by lessons he learned creating and maintaining Jedi.  I believe this is an important talk regardless the specific programming language.</p></div>
<div><p>Next session opened with <a href="https://github.com/arigo" target="_blank">Armin Rigo</a> talking about <a href="https://cffi.readthedocs.org/en/latest/" target="_blank">CFFI</a> - "C Foreign Function Interface and PyPy interrupter. Interesting datum - CFFI is currently ranked 23rd by <a href="http://pypi-ranking.info/alltime" target="_blank">PyPI Ranking</a> above Django and aws cli. Probably thank to the fact that it is integrated in Cryptography package and others. <a href="http://pypy.org/" target="_blank">Pypy</a> - is a python interpreter written in Python (rather then in C comparing to the most common implementation) and is designed for speed optimization.</p></div>
<div><p><a href="http://www.fhnw.ch/personen/martin-christen" target="_blank">Martin Christen</a> had 3 parts to his talk. First he talked about 3d modeling with <a href="https://www.blender.org/" target="_blank">Blender</a>, then he introduced some more low levels possibilities for 3d modeling and he ended up introducing some of the many open source projects he works on. Those projects mostly involve open 3d maps and globe maps.</p></div>
<div><p>After lunch came Matthieu Amiguet, co-founder of <a href="http://www.lescheminsdetraverse.net/" target="_blank">Les Chemins de Travers</a> showed how you can manipulate sound using the relevant packages. This was really outstanding and non standard talk. One of the packages he currently uses is <a href="https://github.com/belangeo/pyo">pyo</a>.</div>
<div>Next talk  was given by <a href="http://www.astro.ethz.ch/people/person-detail.html?persid=200613">Chihway Chang</a> from ETH Zürich who spoke about " Coding / Decoding the Cosmos - Python application in Astrophysics". As she said, and I fully agree - "Python is everywhere in science today". She talked about the found usage of Python in her department, both in Astrophysics dedicated packages (<a href="https://pythonhosted.org/Astropysics/">Astropysics</a>) and using more general purposes packages (SciPy, Numpy, pandas) and packages they write <a href="https://github.com/ethz-asl">themselves</a>. She presented 2 issues they work on - mapping dark matter and calibrating radio telescope with drone. I strongly suggest to see at least a second part of this talk to original scientific thinking.</p></div>
<div><p><img class="alignnone size-full wp-image-594" src="/wp-content/uploads/2016/02/20160205_145917.jpg" alt="20160205_145917" width="3264" height="1836" /></p></div>
<div><p>Michael Rüegg demonstrated a Scrapy pipeline which start in crawling running races results and ends up in elastic search. This was probably the most technical talk of the day and the concrete project was of additional interest for me.</p></div>
<div><p><a href="https://github.com/Jacinda">Jacinda Shelly</a> showed us how magic is done, live coding. Specifically speaking about magic functions in IPython and other cool features.</p></div>
<div><p>Last but not least, <a href="https://github.com/The-Compiler">Florian Bruhin</a> speaking about why and how we should use, how we can expand the basic functionality and so on. In addition he also spoke about other projects he is involved in: <a href="https://github.com/The-Compiler/qutebrowser">qutebrowser</a> - a python browser and <a href="https://tox.readthedocs.org/en/latest/">tox</a> - a generic virtualenv management and test command line tool.<p></div>
<div><p>This is the first edition of the conference and for me it was super interesting and I really loved the mixture of the talks. Hope to be there again next year.<p></div>
