<!-- wp:paragraph -->
<p>Almost a year ago I published a blog post about "<a href="https://tomron.net/2019/08/07/5-ways-to-follow-publications-in-your-field/">5 ways to follow publications in your field</a>". Yesterday I was exposed to a new tool - <a href="https://www.connectedpapers.com/">Connected Papers</a>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Connected Papers present graph of papers that are similar to each other. However, note that this is not a citation tree. Each paper is a node and there is an edge between papers if they are similar.  The similarity matrix is based on co-citation and co-references.<br> The node's colour represent the publication year and the node's size correspond to the number of citation. The graphs are built on the fly given a link or title.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The interface presents the papers' abstract which makes it easier to browse and jump between the different graphs.<br><br>Two small features I can think of is to filter papers according to a publication year and an option to download citation (i.e. bibtex, APA). </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>I believe that I'll used it extensively when working on related work.</p>
