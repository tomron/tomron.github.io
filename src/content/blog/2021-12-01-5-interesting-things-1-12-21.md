<p><strong><u>Python pathlib Cookbook: 57+ Examples to Master It (2021)</u></strong> - I had a post about pathlib for a while in my drafts and now I can delete it since this guide is much more extensive. In short, <code>pathlib</code> is part of the Python standard library since Python 3.4 and it provides an abstraction for filesystem paths over different operating systems. If you still work with <code>os</code> for paths this is a good time to switch.</p>
