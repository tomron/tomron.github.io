<p><strong><span style="text-decoration:underline;">Forestplot</span></strong>&nbsp;- "This package makes publication-ready forest plots easy to make out-of-the-box.". I like it when academia and technology meet and this is really usable, also for data scientists' day-to-day work. The next step would probably be deep integration with scikit-learn to pandas.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://github.com/lsys/forestplot">https://github.com/lsys/forestplot</a></p>

<!-- wp:paragraph -->
<p><strong>Bonus - Python DataViz cookbook</strong>&nbsp;- easy way to navigate between the different common python visualization&nbsp;practices (i.e via pandas vs using matplotlib / plotly /&nbsp; seaborn). I would like to see it going to the next step - controlling the colors, grid, etc. from the UI and then switching between the frameworks but that's a starting&nbsp;point.</p>
