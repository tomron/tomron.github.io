<p><strong><span style="text-decoration: underline">Handling a Regional Outage: Comparing the Response From AWS, Azure and GCP</span></strong> - luckily for the post author, all the major cloud services had regional outages in the last while, so he can compare their responses. <p><strong><u>Python Errors As Values</u></strong> - it is sometimes tough to move from one technology to another - being a newbie all over again, thinking differently, adapting to a new ecosystem, etc. It also makes you ponder concepts that were previously perceived as obvious. For example, the approach for errors in Python. <!-- wp:paragraph -->
<p><strong><span style="text-decoration: underline">croniter</span></strong> - this is a cron utilities package. For example, it helps you find the next time a cronjob should be called given a datetime object. It can also find the previous iteration, validate a cron expression, test if a datetime matches a cron condition, etc.</p>
